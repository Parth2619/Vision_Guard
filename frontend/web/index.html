      What this is

      Purpose

      VisionGuard audits AI-generated chest X-ray reports and flags claims that the image does not visibly support. Each claim resolves to supported, contradicted, or indeterminate, with explicit evidence provenance.

      Pipeline

      A LangGraph state machine runs validate → extract → evidence (torchxrayvision classifier + Grounding-DINO detector) → verify → calibrate (an MLP trained on 6,514 real IU report claims) → critic → risk gate → human review.

      Models

      Three pretrained models used as-is (torchxrayvision DenseNet-121, Grounding-DINO tiny, Qwen2-VL-2B via precomputed Kaggle outputs) and one calibration network trained from scratch on real IU Chest X-Ray reports.

      Measured result

      78.6% agreement with the author on 42 hand-labeled claim/image pairs. F1 for supported 0.87; the system over-claims on ambiguous images 9/11 times — the documented failure mode.

      Honest limitations

      Rule-based claim extractor (not an LLM). No CLIP similarity. Count and spatial verifiers extract typed data but do not run dedicated verifiers. Labels came from a non-expert annotator. 42 cases is small.

      Not for diagnosis

      Research prototype. No clinical validation, no regulatory status, no patient use. Every audit response carries this disclaimer in its JSON.
